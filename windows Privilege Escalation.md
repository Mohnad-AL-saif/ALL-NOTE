


# methodology
#### يعرض **كل معلومات المستخدم الحالي**: الاسم، الـ SID، المجموعات، الصلاحيات (Privileges)، ودرجة النزاهة (Integrity Level).
```
Whoami /all
```


#### يعرض **أرقام المنافذ البعيدة (Remote TCP Ports)** المسموح لها بالخروج حسب **قواعد الجدار الناري**
```
Get-NetFirewallRule -Direction Outbound -Action Allow |
Get-NetFirewallPortFilter |
Where-Object { $_.Protocol -eq "TCP" -and $_.RemotePort -match '\d' } |
Select -ExpandProperty RemotePort -Unique
```
#### يعرض **المنافذ المحلية (Local Ports)** والبروتوكولات المرتبطة بها والمسموح لها حسب **قواعد الجدار الناري**. 
```
Get-NetFirewallRule -Direction Outbound -Action Allow |
Get-NetFirewallPortFilter |
Where-Object { $_.LocalPort -match '\d' } |
Select Protocol, LocalPort -Unique
```





#### يبحث داخل كل المجلدات الفرعية عن كلمة **pass** (بدون حساسية لحالة الأحرف) داخل ملفات الإعدادات **.ini و .cfg و .xml** ويعرض **أسماء الملفات فقط** التي تحتوي عليها. 
```
findstr /SIM /C:"pass" *.ini *.cfg *.xml
```


هذا يطلع فقط InstalledProducts. لكن المشكلة إنه يطلع كل شيء بما في ذلك Microsoft وVMware.

للفلترة، تقدر تستخدم PowerShell مباشرة:
```
Get-ItemProperty HKLM:\Software\Wow6432Node\Microsoft\Windows\CurrentVersion\Uninstall\* | 
Select-Object DisplayName, DisplayVersion, Publisher | 
Where-Object { $_.Publisher -notmatch "Microsoft|VMware" } | 
Format-Table -AutoSize
```
